Which should I pick?

Use the device you’re most tempted on. Android is the furthest along, so it’s the best place to start if you can install an early-access app. The macOS build hasn’t been checked on a clean Mac yet, and Windows isn’t installable. Cross-device sync isn’t available, so each device is its own island: profiles and sessions don’t carry between them.

FAQ

Is NowFocus free?

Yes. Every build is free to download, and nothing is locked behind a payment today. Paid plans may come later, and this page will say so before they do.

Where can I download it?

Nowhere yet. NowFocus isn’t published to any store, and there are no download links. Each platform’s guide says where it stands. Email us to hear when a build is out.

Does it sync between my devices?

Not yet. Each device works on its own, so profiles and sessions don’t carry between them. Cross-device sessions are planned.

Is my data sent anywhere?

No NowFocus server is involved. Profiles, sessions, stats and voice notes stay on your device. On Android, site blocking passes DNS lookups on to your network’s DNS server, and Android’s Google backup may copy the app’s data. The Privacy page has the details.

Is there an iPhone or Linux version?

Not yet. iOS is planned and Linux may follow. There are no dates.

Can NowFocus stop me if I really want to quit?

Not completely. It’s a self-control tool, not a lock: it adds friction, such as typing a sentence and waiting 30 seconds, but someone who owns the device can still uninstall it or switch off its permissions.

Which platform is furthest along?

Android has an early-access build (v0.3). macOS has an early build that hasn’t been released. Windows is in development and has no installer.
