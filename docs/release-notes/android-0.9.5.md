# Android 0.9.5 (versionCode 17) - Play release notes

Play Console limit: 500 characters per language.

## en-US
<en-US>
A video already playing in a blocked app's floating window now gets paused when a block starts, and again if you press play. This uses the optional Notification access; the session screen tells you when it is off. A block that starts while a blocked app is open now closes it. New: Edit a profile straight from the New focus session screen.
</en-US>
